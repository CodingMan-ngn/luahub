How It Works

1. Obfuscation Engine

When you upload a script, our engine compiles it into Lua bytecode and applies a rolling XOR encryption layer. This means the raw source code never touches our database. Executors load the bytecode directly, making it virtually impossible for skiddies to steal your work using standard string dumpers.

2. Loader Generation

Every script gets a unique, secure endpoint. Instead of pasting massive walls of code into an executor, users paste a single loadstring one-liner. This fetches the encrypted payload from our servers, decrypts it in memory, and runs it. Updates are instant—no need to redistribute the script.

3. Key System & Monetization

Developers can enable the Key System to protect their premium scripts. We tie into BoostyLink to generate single-use keys. When a user runs the loader with a key, our backend verifies it and consumes it, ensuring the script cannot be reused without generating a new key. This prevents bot bypasses and ensures you get paid for your work.
