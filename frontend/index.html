Is it safe?

Can Roblox detect the loader?

The loader itself is just a `game:HttpGet` string. The payload runs as standard Lua 5.1 bytecode. Most executors support this natively. Just like any script hub, standard anti-cheat rules apply.

Can someone steal my script?

Because the payload is encrypted bytecode, users cannot simply read the script text. However, no client-side obfuscation is 100% unbreakable. Do not put private API keys directly inside your scripts.
